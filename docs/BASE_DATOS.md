\# Configuración de Base de Datos



\## Proyecto



\*\*Sistema:\*\* Gestión Académica API



La aplicación utiliza MySQL como sistema gestor de base de datos.



\## Base de datos



La aplicación está configurada para utilizar la base de datos:



`gestion\_academica`



\## Variables de entorno



La configuración de conexión se realiza mediante variables de entorno:



```env

DB\_HOST=localhost

DB\_USER=root

DB\_PASSWORD=

DB\_NAME=gestion\_academica
