\# Gestión Académica API



API del proyecto de Gestión Académica.



\## Descripción



Sistema backend desarrollado para gestionar información académica mediante una API.



\## Estructura del proyecto



\- `config/` - Configuración de la aplicación.

\- `controllers/` - Controladores de las operaciones.

\- `middleware/` - Middleware de la aplicación.

\- `routes/` - Rutas de la API.

\- `app.js` - Punto de entrada de la aplicación.

\- `test\_db.js` - Prueba de conexión/configuración de base de datos.

\- `.env.template` - Plantilla de variables de entorno.
